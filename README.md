# flowd

Local, offline, streaming dictation for Linux with LLM cleanup.

Press a hotkey, speak, and watch the text appear live. When you release, a small
local language model cleans up the transcript and types it into whatever window
you had focused. Nothing leaves your machine.

## Status

Under active development. The full architecture and build specification lives in
[`docs/spec.md`](docs/spec.md).

Installation and usage documentation arrives with the first working daemon.
